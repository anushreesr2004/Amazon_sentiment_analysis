# Amazon Sentiment Analysis

**Customer Review Sentiment Classification Using Machine Learning**

## Project Overview

This project analyzes customer product reviews and classifies them into three sentiment categories: **Positive, Negative, and Neutral**.

## Objectives

- Analyze customer opinions from product reviews.
- Perform text preprocessing and cleaning.
- Identify frequently used words.
- Classify reviews using Machine Learning algorithms.
- Compare model performance using evaluation metrics.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- NLP

## Sentiment Categories

- **Positive**
- **Negative**
- **Neutral**

## Model Evaluation

Model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
